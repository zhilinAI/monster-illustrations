# 精妖鬼怪图志

> 汇集《西游记》《山海经》《聊斋志异》《子不语》《三教搜神大全》《列子》《述异记》《太平广记》《搜神记》《阅微草堂笔记》《封神演义》中的精怪、异兽、狐鬼与神祇形象，做成一个可直接双击打开的三层图志站点。

## 📖 项目简介

梳理古籍志怪记载，为每个名目配一幅统一版式的角色设定图（大幅头像 + 正／侧／背四视图 + 竖排题签），并系以回目、篇名与原文摘句。页面按 **作品 → 分类 → 生境** 三层浏览，逐层收窄，最后一层直接铺图；首页带名称检索，可搜作品名，也可直接搜名目。

- **卷一 作品**：11 部作品索引，带名称检索
- **卷二 分类**：《西游记》妖 35 / 精 63 / 鬼 8 / 怪 6 / 神 44 / 佛 14 / 人 39；《山海经》兽 51 / 禽 8 / 神 17 / 民 20；《聊斋志异》狐 18 / 鬼 22 / 妖 15 / 神 9；《子不语》鬼 14 / 兽 16 / 神 9 / 怪 8；《三教搜神大全》天界 45 / 释门 13 / 山川 14 / 人神 31 / 物怪 34 / 护法 13；《列子》神异 5 / 巨兽 4 / 大小人 3 / 微巧 2；《述异记》神祇 12 / 精魅 16 / 化形 10 / 物怪 19；《太平广记》妖 25 / 精 24 / 夜叉 8 / 狐 11 / 鬼 6；《搜神记》狐 9 / 鬼 13 / 兽 17 / 鳞 9 / 精魅 27 / 化形 8；《阅微草堂笔记》鬼 26 / 狐 7 / 物怪 12 / 精魅 4 / 龙蛇 3 / 神 2；《封神演义》妖 22 / 精怪 8 / 神 6 / 异人 11
- **卷三 生境**：西游 海 19 / 陆 65 / 空 51 / 地（穴）74；山海 山 58 / 水 8 / 国 25 / 天 5；聊斋 宅 42 / 野 9 / 水 6 / 冥 5 / 天 2；子不语 宅 21 / 野 19 / 水 4 / 冥 1 / 天 2；三教 天 22 / 山 39 / 水 34 / 地 33 / 宅 22；列子 天 3 / 山 4 / 水 3 / 野 3 / 宅 1；述异记 天 3 / 山 18 / 水 15 / 野 13 / 宅 8；太平广记 山 1 / 水 3 / 野 24 / 宅 32 / 天 0 / 地 12 / 穴 2；搜神记 宅 35 / 野 18 / 水 9 / 山 9 / 树 6 / 地 3 / 天 3；阅微草堂笔记 宅 29 / 野 16 / 山 6 / 树 2 / 天 1；封神演义 天 14 / 山 18 / 野 9 / 宅 5 / 水 1

合计 895 幅设定图，54 类目，57 生境。

## 🚀 打开方式

双击 `index.html` 即可，无需服务器、无需构建、无外部依赖；转发时请连同 `assets/` 目录一起发送。

页面内的地址是 hash 路由，可直接分享某一层：

## 🧭 分类口径

分类与生境均由编者依原文判定，**非原著分类**，只用于检索与编排。

- 西游记：妖＝占山踞洞的魔头，精＝禽兽草木成精，鬼＝尸骸骷髅与幽冥鬼卒，怪＝本相难归者，神＝天界神真星宿龙王，佛＝如来菩萨罗汉尊者，人＝帝王将相僧道吏民；生境分海、陆、空、地（穴）。共 209 条：前 60 条为妖精灵怪摘抄（16:9 四视图），后 149 条为配角神人立绘（2:3 竖图），两套图幅并存、各按原比例排版。原著不载「黑白无常」「降龙罗汉」「龙王夫人」之名，此三条据民间俗称与相邻情节列目；「裴虚己」今本无此人，未收。
- 山海经：兽／禽／神／民四类，依描述文本对本相与居所的写法判定；生境分山、水、国、天。所据描述底本 96 条均已收入，其中相柳、雷神两幅为按同一版式补绘。
- 聊斋志异：狐＝狐族与狐女，鬼＝鬼魂僵尸厉鬼，妖＝山魈宅妖纸人木偶之属，神＝神祇与冥司；生境分宅、野、水、冥、天。共 64 段摘抄，一段一幅。
- 子不语：鬼＝鬼魅骷髅与僵尸旱魃，兽＝兽形精怪（含龙蛇龟鼠草木鸟兽之异），神＝神祇与异人，怪＝器物与草木之怪（太岁、匾上人面、白瓷礅、柳树精等）；生境分宅、野、水、冥、天。原编 47 条的类别标注保留在每条「分类与生境」中，可据此回查。
- 三教搜神大全：天界＝卷一、卷二的三教教主与玉皇帝君，释门＝卷三前十三位释氏圣众，山川＝卷三山川湖海之神，人神＝卷四忠烈城隍与卷六门灶诸神，物怪＝卷五地方神灵与物怪，护法＝卷七天妃与十二元帅；生境分天、山、水、地、宅。原书七卷本无类目，六类由编者依卷次与职司判定。
- 列子：神异＝神人、鬼物、异人与操蛇之神，巨兽＝巨鳌、鲲、鹏与五山禽兽，大小人＝龙伯国之巨人与僬侥、诤人之小人，微巧＝焦螟之微与偃师所造倡者；生境分天、山、水、野、宅。原书八篇为诸子寓言，天瑞、仲尼、力命、杨朱、说符五篇无可摘之精怪形貌，故仅出 14 幅。
- 述异记：神祇＝古神、仙者与远方异人，精魅＝物老成精而具人形器形者，化形＝一身两状之变，物怪＝兽、禽、虫、蛇与征兆之异；生境分天、山、水、野、宅。原编「兽怪／禽怪／虫怪／蛇怪／物怪／妖征」并入物怪，「神／仙／异人／巨人」并入神祇。
- 太平广记：妖＝凶兆与物怪拼装之形，精＝器物明器家宅之魅，夜叉＝赤发青身兽爪的异域鬼族，狐＝通灵变化的狐女狐妖，鬼＝鬼魅亡魂；沿用原页所标五部类，生境按引文所见居所判以山、水、野、宅、天、地、穴七境，逐条附所出书目。原书五百卷为类书编排，本图志仅取其中精妖鬼怪 74 条。
- 搜神记：狐＝狐与狸成精（白狐、斑狐、老狸、阿紫），鬼＝鬼魅亡魂（恶鬼、三疫鬼、无头鬼、亡魂），兽＝走兽水族成精（羊、鹿、獭、豕、鼠、犀犬、大鳀、马皮蚕女），鳞＝蛇龙龟鼍（巨蛇、华亭大蛇、蛇翁、月下鼍、龟鼍化人），精魅＝草木山川禽虫星神与器宅之魅（彭侯、树神、山都、冶鸟、度朔君、饭臿、宅妖），化形＝人形藏妖（皓首书生、偶人、冢中美人、女鬼、落头民）；生境分宅、野、水、山、树、地、天。原目录「精怪-兽类／精怪-水族」并入兽，「树/植物精、山川精魅、神灵/星宿、精怪-禽鸟类、精怪-昆虫/爬虫、其他精怪」并入精魅；鬼类五条重名者以所出章节消歧（阮瞻、宗定伯、杨度、苟奴、文颖）。本图为皮克斯3D版美术设定集（同一版式的数字创作），沿用其名目与摘抄，另立分类与生境。

- 阅微草堂笔记：鬼＝鬼魅亡魂（含罗刹、夜叉、山魈与尸变），狐＝狐妖，物怪＝物怪与巨物（山兽、蓑衣黑物、巨蝠与巨人），精魅＝精魅化形（白发黑媪、美妇等），龙蛇＝龙蛇，神＝神祇；生境分宅、野、山、树、天。原书二十四卷分五书（滦阳消夏录、如是我闻、槐西杂志、姑妄听之、滦阳续录），本图志依摘抄 docx 取出 54 条形貌描写，一条一幅，纪评为编者所附、引文已回检；十二张同题材备选图未收录。

- 封神演义：妖＝兽禽虫蛇狐之化形（五妖、狐群、瘟部四使、梅山畜怪与三妖），精怪＝物老成怪（顽石、龙须虎、泽中怪物、灯头马善与桃柳之精），神＝神祇与佛门法身（孔宣、文殊普贤慈航三大士、二十八宿），异人＝异人神将（雷震子、辛环、土行孙、余化余元与哪吒诸相）；生境分天、山、野、宅、水。自第十三回至第九十七回摘出 47 条形貌描写，一条一幅；拆「高明高觉」一条为桃精柳鬼两条（第90回）。四视图为编者依既有版式补绘，其中普贤法身、高明、高觉、常昊、三妖、龙须虎六图为后补。

条目若与原文记载有出入，以原文为准，可在 `tools/taxonomy*.json` 中改写后重新生成。

## 🔧 重新生成

依赖 Python 3.9+ 与 Pillow（仅预处理图片时用到）。

```bash
python tools/build_rosters.py             # 列子 / 述异记 摘抄 → _roster.json + taxonomy（改分类口径后先跑这条）
python tools/prepare_images.py            # 原图 → assets/（已做则跳过；可加 xyj / shj / lz / zby / sjs / lzl / syj / tpg / ssj / yw / fs 只跑一部）
python tools/build_site.py                # 数据 + 分类表 + 模板 → index.html
python tools/check_site.py                # 校验条数、分类计数、图片引用
```
